2 — Choose a tweeter
Compatible = 3×Fs below mid beam ceiling. Beam ceilings: SB12PFCR25-4 / SB12PACR25-4 = 2,184 Hz → Fs must be <728 Hz. HiVi B4N = 2,109 Hz → Fs must be <703 Hz. Notes column flags any tweeter that is INCOMPATIBLE with B4N but fine with SB12.
Power at burst = watts needed when sub hits 101 dB peak. Ideal xover = √(3×Fs × beam_ceiling) for primary mid (SB12PFCR25-4).

3 — Compact spacing only (DSA90-8 mid)
DSA90-8 is underpowered for full SPL (max 97.7 dB at 20W — 3.3 dB short at burst). Use only if minimum vertical driver spacing is the priority. Its higher beam ceiling (2,608 Hz) opens up tweeters unavailable with 4" mids, including some with small ODs for tight spacing.
