Narrow Spacing — Minimum Centre-to-Centre Distance

With drivers stacked vertically, baffle width is set by the mid's OD — the tweeter doesn't change it. What matters is the vertical centre-to-centre distance d, which controls the comb null frequency: f_null = c / (2d). The rule: d must be small enough that f_null ≥ crossover, or vertical lobing lands in the listening band.

Examples: d=68mm → f_null=2,522Hz (above the 2,300Hz crossover ✓) · d=110mm → f_null=1,559Hz (in-band ✗). Narrower is acoustically better, not just physically smaller.

All five use DSA90-8 mid (90mm OD, £29.71 Willys / SI €34.95). Spacing column = vertical centre-to-centre distance. Critical limit: d < c / (2 × f_xover) — below this, first comb null is above the crossover frequency.
