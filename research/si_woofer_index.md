## Key Reference

- **Fs margin target:** Fs ≤75Hz → 2× at 150Hz crossover
- **Xmax ≥ 2.5mm minimum; ≥ 4mm preferred**
- **Sensitivity 82–90dB workable** (outside range: >8dB DSP correction)
- **Beaming limit:** f = c / (π × √(Sd/π)) — must be above crossover frequency
- **Frame OD → min baffle width = OD + 40mm**
- **Power at ref (98dB):** P = 10^((98 − Sens) / 10) watts
